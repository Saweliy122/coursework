1. Введение

Теория игр представляет собой современный математический аппарат анализа конфликтных ситуаций и занимает важное место в прикладной математике. Актуальность темы обусловлена ростом размерности практических задач, где классические аналитические методы — симплекс-метод и графический подход — становятся вычислительно затратными.

Цель работы — исследовать эффективность применения случайных чисел для численного определения оптимальных смешанных стратегий в матричных играх двух лиц с нулевой суммой.

Ключевая идея. Метод Монте-Карло позволяет находить приближённое равновесие Нэша за приемлемое время даже для матриц большой размерности, где детерминированные методы неприменимы.

2. Постановка задачи

Матричная игра двух игроков задаётся тройкой (X, Y, K), где X = {x₁, …, xm} — стратегии первого игрока, Y = {y₁, …, yn} — стратегии второго, а K: X × Y → ℝ — функция выигрыша. В матричной форме игра описывается платёжной матрицей A = (aij).

Смешанные стратегии задаются векторами вероятностей p = (p₁, …, pm) и q = (q₁, …, qn), лежащими в симплексах Sm и Sn. Функция выигрыша в смешанном расширении:

H(p, q) = Σi=1..m Σj=1..n pi qj aij = pT A q

Задача сводится к поиску седловой точки:

maxp ∈ Sm minq ∈ Sn H(p, q) = minq ∈ Sn maxp ∈ Sm H(p, q) = v

3. Алгоритм случайного поиска

Предлагаемый подход основан на многократной генерации случайных вероятностных векторов в симплексе стратегий. Для равномерного распределения точек на симплексе используется нормирование экспоненциально распределённых величин:

pi = ξi / (ξ₁ + … + ξm),   ξi = −ln(ui),   ui ∈ [0, 1]

Основные шаги алгоритма

  • Генерация случайной стратегии первого игрока p на симплексе Sm.
  • Вычисление вектора ожидаемых выигрышей ej = Σi pi aij.
  • Определение гарантированного выигрыша vmin = minj ej.
  • Обновление лучшей стратегии p* и оценки v* = max(v*, vmin).
  • Аналогичные операции для стратегии q второго игрока.
  • Повтор шагов до заданного числа итераций N.

4. Результаты экспериментов

Сравнительное тестирование проводилось на матричных играх размерности 4×4 – 20×20 с элементами из диапазона [−10, 10]. Использовались три генератора псевдослучайных чисел: стандартный ЛКГ, вихрь Мерсенна и субоптимальный ЛКГ.

5. Заключение

Разработан итерационный алгоритм численного поиска оптимальных смешанных стратегий, основанный на генерации случайных точек в симплексе. Установлено, что использование качественного генератора (вихря Мерсенна) повышает точность решения на 32% и сокращает число итераций на 34% по сравнению с субоптимальным ЛКГ.

Практическая значимость работы определяется возможностью применения алгоритма в задачах стратегического планирования, ценовой оптимизации на олигополистических рынках и выбора инвестиционных портфелей.
